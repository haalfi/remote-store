## Pitfalls comparables met

List children: Directory markers changed policy across Hadoop releases. A missing folder is an error in Hadoop, optional in pyarrow and tolerated in OpenDAL. Ordering is not guaranteed in object_store, differs on S3 directory buckets and Azure HNS, and is lexicographic in gocloud. Pages can be short or empty; listing caches go stale.
