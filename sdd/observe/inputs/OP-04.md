## Pitfalls comparables met

Replace atomically: Object-store PUT is atomic, but object_store's local temp files leak into the key space. Windows needs `os.replace`, SFTP `posix_rename`. A durable replace needs a directory fsync. On S3 the latest timestamp wins.
