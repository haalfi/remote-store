# SFTPBackend

API reference for `SFTPBackend` — stores files on any SSH/SFTP server using
paramiko. Explicit host key verification and Azure Key Vault PEM support.
For usage patterns, configuration, and examples, see the
[SFTP Backend Guide](../../backends/sftp.md).
