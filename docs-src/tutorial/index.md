# Tutorial

Tutorials are learning-oriented. They guide you from zero to working code,
step by step, and each one ends with something that runs. Start here if you
are new to `remote-store`.

## Getting Started

[Getting Started](getting-started.md) is the recommended first step. It walks
through installing `remote-store`, connecting a `Store` to a backend, and
reading and writing files for the first time.

Every other concept in the docs builds on this foundation.

## Examples

The [Examples](examples/) section contains runnable scripts that cover common
patterns: uploading files, switching backends, using extensions, and
integrating with PyArrow or Dagster.
