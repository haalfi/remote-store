API reference for the native async extensions in `remote_store.aio.ext`. These are the async-native counterparts of selected [synchronous extensions](https://docs.remotestore.dev/stable/reference/api/extensions/index.md).

| ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------- |
| [aio.ext.write](https://docs.remotestore.dev/stable/reference/api/aio/extensions/write/index.md) | Async write helpers with guaranteed client-side content hashing |
